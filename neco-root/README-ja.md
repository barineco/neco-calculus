# neco-root

[English](README.md)

`neco-root` は、厳密な多項式について、検証済みの根区間、根区間の縮小、重複度の分類、区間上の符号の判定、候補点の根の分類を提供するクレートです。

## 主要機能

**検証済みの根区間**

根区間 ( 根を含むことを検証した区間 ) を確定する根拠は、検証済みの符号変化か、二進有理数 ( 分母が 2 の冪である有理数 ) で厳密に表せる偶数重複度の根のどちらかです。公開する結果の型は内部表現を隠しており、内容は観測用メソッドを通じて返します。

**根区間の縮小と縮小の証拠**

根区間の縮小では、二分法か Newton 二分法で根区間を狭め、縮小の証拠 ( `ConvergenceWitness` ) を作成します。縮小の証拠は、手法、収束状態、反復回数、初期区間と最終区間を保持します。Newton 二分法で微分の包含区間が零を含む場合は二分法に切り替え、その理由と回数を縮小の証拠に残します。

**区間上の符号の判定と候補点の根の分類**

どちらの操作も、多項式、区間、候補点、微分階数の上限、区間評価の精度をまとめた要求 ( `MembershipJudgmentRequest` ) を受け取ります。候補点は、呼び出し側が区間内から選んで渡す二進有理数の点です。

`classify_region_sign` は、区間上の多項式の符号を判定し、判定の結果 ( `RegionSignJudgment` ) を返します。

結果の `sign` は、判定した符号を `RegionSign` の値で返します。多項式が定数の場合、判定した符号は係数の符号と同じです。

次数が 1 以上の多項式では、まず候補点のうち多項式の根である点を調べます。区間の内部に奇数重複度の根があれば、符号が区間内で変わると判定します。根が端点の根か偶数重複度の根だけであれば、多項式が区間内で零を取る ( `RegionSign::ContainsZero` ) と判定します。

候補点のうち多項式の根である点が無い場合は、区間評価で多項式の値の範囲を求めます。この範囲が正の側か負の側の一方に収まれば、符号を正か負に確定します。範囲が零を含む場合は両端における多項式の値の符号を比べ、一方が正で他方が負であれば、符号が区間内で変わると判定します。それ以外の場合 ( 端点における多項式の値が零の場合を含む ) は符号を未確定とし、結果の符号は `RegionSign::Undetermined` になります。

`locate_membership_transitions` は、候補点のうち多項式の根である点と、その重複度を確定する操作です。

この操作は、重複度が奇数の根を、符号が変わる遷移 ( `Transition` ) に、重複度が偶数の根を、多項式が符号を保ったまま零に接する点 ( `SingularContact` ) に分類します。

**型付きの失敗**

`RootFailure` は、入力、多項式、区間、代数演算の失敗と、計算資源の上限超過による失敗を、それぞれの内容とともに保持します。

## 仕様と制約

| 操作 | 制約 | 上限に対する結果 |
| --- | --- | --- |
| **候補解析** | 候補点 4,096 件以下 | 上限を超える要求には `RootFailure::ResourceLimit` を返す |
| **重複度解析** | 微分階数 64 以下 | 上限を超える階数には `RootFailure::ResourceLimit` を返す |
| **根区間の縮小** | 反復回数 19 以下 | 上限を超える回数には `RootFailure::ResourceLimit` を返す |
| **区間評価** | 精度 256 ビット以下 | 上限を超える精度には `RootFailure::ResourceLimit` を返す |

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-root = "0.1"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。結果と失敗の意味は、どちらの構成でも同じです。

```toml
[dependencies]
neco-root = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 正規形の多項式、微分、区間評価
* [`neco-algnum`](https://docs.rs/neco-algnum): 厳密な代数的数と包含区間
* [`neco-bigint`](https://docs.rs/neco-bigint): 厳密な二進有理数の演算
* [`neco-formsum`](https://docs.rs/neco-formsum) と [`neco-monomial`](https://docs.rs/neco-monomial): 二進有理数の点を実代数的数へ変換するための形式和と単項式
