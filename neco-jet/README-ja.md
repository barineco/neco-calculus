# neco-jet

[English](README.md)

`neco-jet` は、一点における厳密な微分値の有限列を、検証済みの階数と値の整合とともに提供します。

## 主要機能

**検証済みの微分列**

0 階の要素が指定された値と等しい、空でない微分列を構成します。

**階数を保つ観測**

観測用メソッドは微分階数を保ちます。シフト操作は一階微分から始まる列を返します。

**型付きの失敗の来歴**

列、階数、多項式、代数演算の失敗を `JetFailure` から区別できます。

## 不変条件と検証規則

| 対象 | 検証規則 | 結果 |
| --- | --- | --- |
| **微分列** | 0 階の値を含む 1 個以上の要素を持つ | 空の列へ `JetFailure` を返却 |
| **0 階の値** | 個別に指定した値と等しい | 不一致へ `JetFailure` を返却 |
| **微分階数** | 64 以下 | 上限を超える列を保存する前に `JetFailure` を返却 |
| **シフト** | 元の微分順序を保持 | 一階微分から始まる末尾列を生成 |

## ランタイム構成

既定では標準ライブラリと連携します。

```toml
[dependencies]
neco-jet = "0.1"
```

標準ライブラリのない環境では、動的メモリ確保だけを使います。微分列と失敗の意味は同じです。

```toml
[dependencies]
neco-jet = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 多項式の微分と関連する失敗
* [`neco-algnum`](https://docs.rs/neco-algnum): 厳密な微分値
