# neco-jet

[English](README.md)

`neco-jet` は、一点における厳密な微分値の有限列を提供するクレートです。列を構成する時には、微分の階数が上限以下であることと、関数値と 0 階の要素が一致することを検証します。

## 主要機能

**検証済みの微分列**

`Jet::from_value_and_derivatives` は、点における関数値 ( `value` ) と、空でない微分値の列から微分列を構成します。構成時には、列の 0 階の要素が関数値と等しいことを確かめます。

**階数を保つ観測**

シフト操作は、1 階微分から始まる列を返します。観測用メソッドで読み出す各要素は、微分の階数と対応したままです。

**型付きの失敗**

`JetFailure` の種類で、失敗の原因を区別できます。原因は、空の列、関数値と 0 階の要素の不一致、列の範囲外の階数の参照、階数の上限超過、代数演算の失敗のいずれかです。

## 不変条件と検証規則

| 対象 | 検証規則 | 結果 |
| --- | --- | --- |
| **微分列** | 0 階の値を含む 1 個以上の要素を持つ | 空の列には `JetFailure` を返す |
| **0 階の値** | 構成時に渡した関数値と等しい | 値が異なる場合は `JetFailure` を返す |
| **微分階数** | 64 以下 | 上限を超える列には、格納する前に `JetFailure` を返す |
| **シフト** | 元の微分の順序を保つ | 1 階微分から始まる残りの列を生成する |

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-jet = "0.1"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。微分列と失敗の意味は、どちらの構成でも同じです。

```toml
[dependencies]
neco-jet = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 微分階数の型 ( `DerivativeOrder` )
* [`neco-algnum`](https://docs.rs/neco-algnum): 厳密な微分値
