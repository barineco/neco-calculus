# neco-calculus

[English](README.md)

`neco-calculus` は、多項式と有理関数の微積分を厳密に行う公開操作をまとめたクレートです。厳密評価、有限の微分列、検証済みの包含区間 ( 真の値を含むことを検証した区間 ) 、根区間の縮小、区間上の符号の判定、候補点の根の分類を組み合わせます。

根区間の縮小は、根を含む区間を二分法か Newton 二分法で狭める操作です。縮小の過程は、手法、収束状態、反復回数、初期区間と最終区間を持つ縮小の証拠 ( `ConvergenceWitness` ) に残ります。区間上の符号の判定では、区間の上で多項式の符号が一定か、区間内で変わるかを調べます。一方、候補点の根の分類は、呼び出し側が渡した候補点のうち多項式の根である点を、重複度が奇数で符号が変わる根と、重複度が偶数で符号を保つ根に分けます。

## 主要機能

**曲面と陰関数の多項式の厳密評価**

曲面多項式 ( `SurfacePolynomial` ) は、変数 u, v の有理係数の多項式です。有理パラメータ曲面では、x, y, z の座標と三座標に共通の分母を、それぞれ曲面多項式で表します。陰関数多項式 ( `ImplicitPolynomial3` ) は、変数 x, y, z の実代数的数係数の多項式です。

どちらの構成でも、項は指数の組の辞書式の昇順に並びます。曲面多項式の構成では、同じ指数の組の項を合算し、係数が零の項を除きます。陰関数多項式の構成は、係数が零の項や、指数の組が同じ項を含む入力に失敗を返します。また、評価関数は、厳密値または検証済みの包含区間を、内部表現を隠した結果型に包んで返します。

**有理関数、微分列、根の操作**

有理関数の評価と微分列 ( `Jet` ) も公開しています。また、根の操作には、根区間の縮小、区間上の符号の判定、候補点の根の分類のための公開関数があります。

* `refine_root_bisection`: 二分法で根区間を縮小
* `refine_root_newton_bisection`: Newton 二分法で根区間を縮小
* `expose_region_sign`: 区間上の符号の判定の結果 ( `RegionSignJudgment` ) を取得
* `expose_membership_transitions`: 候補点の根の分類を取得

依存クレートが返した失敗は、失敗に付随する値も含めて、そのまま保持されます。

**超越関数の評価**

正弦、余弦、指数関数、実数の指数によるべき乗を、区間で与えた引数について、要求した絶対精度で評価します。入力区間に正弦や余弦が極値を取る点が含まれる場合は、その極値も包含区間に含めます。極値を取る点が入力区間に含まれるかは、外向きに丸めた円周率の包含区間を用いて判定します。

要求精度を p ビットとすると、目標の幅は 2^-p です。評価の結果は、厳密値、幅が目標の幅以下の包含区間、未確定の結果のいずれかです。

評価では、結果の包含区間の幅を見積もります。正弦と余弦では、計算した包含区間の幅を幅の見積もりとします。指数関数では、引数区間の幅に導関数の大きさの上界を掛けた量が幅の見積もりです。べき乗では、底と指数のそれぞれについて、その変数の区間の幅と、その変数による偏導関数の大きさの上界との積を求め、二つの積の和を幅の見積もりとします。この見積もりが目標の幅を上回った場合は未確定の結果となり、それまでに確定した区間を保持します。この区間の実際の幅が、目標の幅以下の場合もあります。

* `evaluate_transcendental_function`: `TranscendentalFunction` で指定した関数を評価
* `evaluate_transcendental_power`: 厳密に正の区間を底とする、実数の指数によるべき乗を評価
* `TranscendentalEvaluation::undetermined_achieved`: 未確定の結果が保持する区間を取得
* `TranscendentalFunction`: 評価できる関数の種類
  * `Sine`
  * `Cosine`
  * `Exponential`

**倍精度浮動小数点数への証明付き射影**

評価の結果は、最も近い倍精度浮動小数点数 ( `f64` ) へ射影できます。射影した値には、丸める前の包含区間と、丸めによる実際の絶対誤差が付きます。この誤差の大きさは、包含区間の幅 ( 目標の幅以下 ) と、隣り合う倍精度浮動小数点数の間隔で決まります。

* `TranscendentalEvaluation::certify_f64`: 厳密値または包含区間から `CertifiedF64` を取得

**検証済みの超越関数の包含区間**

`construct_transcendental_evaluation` は、呼び出し側が渡した評価の候補から、超越関数の評価の結果を構成します。評価の候補 ( `TranscendentalEvaluationCandidate` ) は、値と来歴の組です。構成の前には、候補の来歴が呼び出し側の要求する来歴と一致すること、要求精度が 1 から 256 ビットであること、包含区間の幅が目標の幅以下であることを検証します。

**証明付きの求積**

端点が二進有理数 ( 分母が 2 の冪である有理数 ) の閉区間で積分を求め、その包含区間を返します。要求精度を p ビットとすると、包含区間の幅は目標の幅 2^-p 以下です。

求積では、積分区間を小区間に分割し、各小区間の中点で被積分関数を Taylor 展開します。求積次数 ( `QuadratureOrder` の値 ) は、この展開で剰余項の前に残す偶数階の項の数です。剰余項の包含区間は、求積次数の 2 倍の階数の微分が小区間上で取る値域から求めます。

被積分関数は `IntervalDifferentiable` を実装し、関数値と偶数階の微分の値域を包含区間として返します。求積の結果には、剰余項の包含区間の幅の和と、分割した小区間の数が含まれます。

* `evaluate_quadrature`: 被積分関数の閉区間上の積分を包含区間で計算
* `IntervalDifferentiable`: 被積分関数が関数値と微分の値域を返すためのトレイト
* `QuadratureOrder`: 求積次数を指定
* `QuadratureRefinement`: 求積次数と、小区間の数の上限を指定
* `QuadratureEvaluation::certify_f64`: 包含区間から証明付きの倍精度浮動小数点数を取得

**観測可能な結果の来歴**

超越関数の評価、曲面の検証付き評価 ( `evaluate_surface_checked` ) 、求積の結果は、来歴を保持しています。来歴は、所有者の識別子、評価の要求、計算した実装の識別情報の三つから成ります。

評価の要求は、消費点 ( 結果を受け取る利用箇所 ) の識別子、式の識別子の列、判定の指定、要求精度を含みます。判定の指定は、消費点が求める厳密な判定の種類 ( 零、等値、符号、縮退 ) と、その判定で調べる式 ( 等値の判定では二つの式 ) を表します。判定で調べる式の識別子は、式の識別子の列に含まれます。式の識別子 ( `ExprId` ) は、neco-expr の式グラフの節点を指します。また、計算した実装の識別情報は、版と公開 API の識別子の組です。結果の値に加えて、来歴の各要素も観測用メソッドで取得できます。

* `owner`: 所有者の識別子 ( `OwnerId` )
* `requirement`: 評価の要求 ( `ExactExpressionRequirement` )
* `source`: 計算した実装の識別情報 ( `NecoImplementationSource` )

## 仕様と制約

| 操作 | 制約 | 上限に対する結果 |
| --- | --- | --- |
| **曲面多項式の構成** | 項数 4,096 以下、各指数 256 以下 | 上限を超える入力には `CalculusFailure` を返す |
| **陰関数多項式の構成** | 項数 4,096 以下 | 上限を超える入力には `CalculusFailure` を返す |
| **微分と根の操作** | 依存クレートが定める階数、候補数、反復回数、精度の上限を満たす | 依存クレートが返す、計算資源の上限超過による型付きの失敗を保持する |
| **超越関数の評価** | 精度 1 から 256 ビット、底は 0 より大きい値 | それ以外の精度または底には `EvaluationFailure` を返す |
| **級数の項数の上限** | 引数の大きさと作業精度 ( 要求精度より 96 ビット多い精度 ) から決まる級数の項数が、256 以下に収まる | 依存クレートの型付きの失敗を包んだ `EvaluationFailure` を返す |
| **未確定の結果** | 幅の見積もりが目標の幅を上回る | 確定できた区間を成功値として返す。その幅が目標を満たす場合もある |
| **倍精度への射影** | 結果が厳密値または包含区間を保持する | 未確定の結果には `TranscendentalCertificationFailure` を返す |
| **超越関数の検証** | 評価の候補の来歴が要求と一致し、要求精度が 1 から 256 ビットで、包含区間の幅が目標の幅以下 | 来歴が要求と異なる候補には `EvaluationFailure::Lower` を返す。要求精度が範囲外の場合と、包含区間の幅が目標の幅を上回る場合には `EvaluationFailure::PrecisionShortage` を返す |
| **求積** | 下端が上端より小さく、要求ビット数が 1 から 256 | 型付きの失敗を返す。幅が要求より大きいまま終わった場合は、到達した包含区間を失敗の値に保持する |
| **小区間への分割** | 求積次数の 2 倍が 64 以下、小区間の数が 65,536 以下 | 上限を超える次数または小区間の数には `CalculusFailure` を返す |
| **結果の構成** | 結果を表す構造体の型 ( 多項式の評価、有理関数の評価、有理係数の多項式の評価、区間評価、超越関数の評価、求積の各結果と、座標の包含区間 ) は、フィールドが非公開 | これらの結果は、本クレートの公開関数だけが生成する。超越関数の評価の結果、曲面の検証付き評価が返す座標の包含区間、求積の結果には来歴が付き、その来歴は観測できる。曲面と陰関数の評価が返す列挙型は、結果が厳密値の場合に、その値を公開のフィールドで保持する。曲面の検証付き評価では、この列挙型が座標の包含区間を保持する |

## ランタイム構成

既定の構成では標準ライブラリを使い、全ての依存クレートでも標準ライブラリへの対応を有効にします。

```toml
[dependencies]
neco-calculus = "0.2"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。公開する値、結果、失敗の意味は、どちらの構成でも同じです。

```toml
[dependencies]
neco-calculus = { version = "0.2", default-features = false }
```
