# neco-calculus

[English](README.md)

`neco-calculus` は、厳密な多項式と有理関数の微積分を提供する公開操作の入り口です。厳密評価、検証済みの包含区間、有限の微分列、根の細分化、局所的な所属解析を組み合わせ、型付きの結果の出自を保持します。

## 主要機能

**形状多項式の厳密評価**

曲面多項式と陰関数多項式の構成時に項を正規順序へ並べます。評価は非公開表現の結果型を通じて、厳密値または検証済みの包含区間を返します。

**有理関数、微分列、根の操作**

有理関数の評価、微分列、根の細分化、所属解析を公開し、依存先の失敗とその内容を保持します。

**検証済みの超越関数区間**

評価操作が結果と出自を構成する前に、接続処理が式の同一性、精度、包含区間の幅を検証します。

**観測可能な結果の出自**

包含区間の結果には、計算方法と入力式が保持されます。観測用メソッドからは、包含区間・計算方法・入力式を取得できます。

## 仕様と制約

| 操作 | 制約 | 上限に対する結果 |
| --- | --- | --- |
| **曲面多項式の構成** | 項数 4,096 以下 | 上限を超える入力へ `CalculusFailure` を返却 |
| **陰関数多項式の構成** | 項数 4,096 以下 | 上限を超える入力へ `CalculusFailure` を返却 |
| **微分と根の操作** | 依存先が定める階数、候補数、反復回数、精度の上限を満たす | 依存先の型付きの計算資源の失敗を保持 |
| **超越関数の検証** | 式の同一性、要求精度、包含区間の幅が一致 | 無効な候補へ `TranscendentalConnectorFailure` を返却 |
| **結果の構成** | 微積分の操作が結果の出自を供給 | 観測可能な出自を持つ非公開表現の結果を生成 |

## ランタイム構成

既定では標準ライブラリと連携し、全ての依存先で標準ライブラリ対応を有効にします。

```toml
[dependencies]
neco-calculus = "0.1"
```

標準ライブラリのない環境では、動的メモリ確保だけを使います。公開値、結果、失敗の意味は同じです。

```toml
[dependencies]
neco-calculus = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 正規多項式と検証済みの区間評価
* [`neco-rational`](https://docs.rs/neco-rational): 厳密有理関数と定義域の検証
* [`neco-jet`](https://docs.rs/neco-jet): 有限の微分列
* [`neco-root`](https://docs.rs/neco-root): 根と局所的な所属の検証結果
* [`neco-algnum`](https://docs.rs/neco-algnum): 厳密値
* [`neco-bigint`](https://docs.rs/neco-bigint): 二進有理数の演算
* [`neco-expr`](https://docs.rs/neco-expr): 安定した式の識別子
