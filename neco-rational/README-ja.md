# neco-rational

[English](README.md)

`neco-rational` は、正規多項式から構成する厳密有理関数と、検証済みの点および区間の定義域を提供します。

## 主要機能

**検証済みの有理関数**

正規化した分子と分母の多項式を保存し、分母多項式が零でないことを構成時に確立します。

**点の厳密評価**

関数の定義域に含まれる値について、厳密な商を返します。

**検証済みの区間評価**

入力区間上で定義される全ての商を含む二進有理数区間を返します。

**型付きの失敗の来歴**

定義域、多項式、代数演算、計算資源の失敗を `RationalFailure` から区別できます。

## 不変条件と検証規則

| 対象 | 検証規則 | 結果 |
| --- | --- | --- |
| **構成** | 分母多項式が零でない正規値を持つ | 零多項式へ `RationalFailure` を返却 |
| **点の評価** | 分母の値が零でない | 極に対して型付きの定義域の失敗を返却 |
| **区間評価** | 分母の包含区間が零を除外する | 極を含む区間へ型付きの定義域の失敗を返却 |
| **計算資源** | 多項式の係数数と精度の上限を満たす | 依存先の計算資源の失敗を保持 |

## ランタイム構成

既定では標準ライブラリと連携します。

```toml
[dependencies]
neco-rational = "0.1"
```

標準ライブラリのない環境では、動的メモリ確保だけを使います。関数と失敗の意味は同じです。

```toml
[dependencies]
neco-rational = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 正規化した分子と分母の多項式
* [`neco-algnum`](https://docs.rs/neco-algnum): 厳密な実代数的評価値
* [`neco-bigint`](https://docs.rs/neco-bigint): 厳密な二進有理数区間の演算
