# neco-rational

[English](README.md)

`neco-rational` は、正規形の多項式から構成する厳密な有理関数を提供するクレートです。点と区間のそれぞれについて、定義域に含まれることを検証して評価します。

## 主要機能

**検証済みの有理関数**

正規形の分子と分母の多項式を保持し、分母の多項式が非零であることを構成時に確かめます。

**点の厳密評価**

関数の定義域に含まれる値については、厳密な商が得られます。

**検証済みの区間評価**

区間評価の結果は、入力区間上で定義される全ての商を含む、二進有理数 ( 分母が 2 の冪である有理数 ) の区間です。

**型付きの失敗**

定義域、多項式、代数演算のどこで生じた失敗か、計算資源の上限超過による失敗かを、`RationalFailure` の種類で区別できます。

## 不変条件と検証規則

| 対象 | 検証規則 | 結果 |
| --- | --- | --- |
| **構成** | 分母の多項式が正規形の非零多項式である | 分母が零多項式の場合は `RationalFailure` を返す |
| **点の評価** | 分母の値が非零 | 極では、定義域外を表す型付きの失敗を返す |
| **区間評価** | 分母の包含区間が零を含まない | 極を含む区間には、定義域外を表す型付きの失敗を返す |
| **計算資源** | 多項式の係数の数と精度の上限を満たす | 依存クレートが返す、計算資源の上限超過による失敗を保持する |

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-rational = "0.1"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。有理関数と失敗の意味は、どちらの構成でも同じです。

```toml
[dependencies]
neco-rational = { version = "0.1", default-features = false }
```

## 依存クレート

* [`neco-polynomial`](https://docs.rs/neco-polynomial): 正規形の分子と分母の多項式
* [`neco-algnum`](https://docs.rs/neco-algnum): 実代数的数による厳密な評価値
* [`neco-bigint`](https://docs.rs/neco-bigint): 二進有理数の区間の厳密な演算
